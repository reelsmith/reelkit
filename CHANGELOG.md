# Changelog

## 0.3.0 - 2026-09-22
- `finish` accepts a folder and processes every video inside it.
- New `thumb` command exports a cover frame as a JPG.

## 0.2.0 - 2026-09-22
- New `info` command: pass/fail checklist for resolution, duration, leftover metadata and loudness.
- New `--dry-run` flag prints the exact ffmpeg commands instead of running them.

## 0.1.0 - 2026-09-22
- First release: `vertical`, `loud`, `strip`, `faststart` and `finish`.
